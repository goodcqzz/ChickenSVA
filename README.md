## ✨ Core Features

### 🎯 Genotype Imputation Workbench
- **Reference Panel Management**: Automatic loading of indexed reference panels (e.g., 2,063-sample GRCg7b panel)
- **VCF File Upload**: Supports .vcf, .vcf.gz, and .bcf formats, up to 50 MB
- **Parameter Configuration**: Advanced parameters including thread count, window size, and overlap region
- **Task Execution**:High-accuracy genotype imputation powered by the **Beagle** software
- **Real-time Monitoring**: Task status polling, progress display, and execution logs
- **Result Download**: Result Download

### 🔍 SV Query Explorer
- **Gene-based Query**: Query SVs by gene name (e.g., BRCA1, TP53)
- **Region-based Query**: Query by chromosomal position range
- **ID Query**: Exact query by specific SV ID
- **Statistical Overview**: Visualization of SV type distribution, chromosomal distribution, and sample statistics



### 📊 Task Management Center
- **Task List**: View all historical tasks
- **Status Filtering**: Queued / Running / Completed / Failed
- **Operations: Retry**:failed tasks, cancel running tasks, and download results
- **Detail View**: Task execution details and real-time logs
